# controle customizado
este é um repositorio dedicado ao código do gamepad do escape room.

no atual momento os jogadores precisam encontrar uma chave fisica para destravar o controle. caso exista algum problema com a chave futuramente eu pretendo fazer uma versao do controle onde ela nao é necessaria

o controle foi feito usando uma central multimida de carro como carcaça, botões de fliperama e outros componentes eletrônicos. Foi inteiramente feito pensando para ser reconhecido pelo computador como um controle de videogame usando para isso um arduino leonardo. Ele também conta com um display LCD I2C para uma interface de comunicação com o jogador.
